# Platform Infrastructure and Financial Core

The controlled platform paper covers authority boundaries, cloud runtime, service ownership, data planes, identity, blockchain connectivity, the double-entry financial core, custody, contracts, resilience, security, compliance, and release assurance.

The reader-facing chapters explain how to use and verify the product. These controlled chapters define how the system must behave under success, ambiguity, failure, and recovery.
