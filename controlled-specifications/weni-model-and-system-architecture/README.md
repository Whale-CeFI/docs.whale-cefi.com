# WENI Model and System Architecture

The controlled WENI paper covers model lineage, domain adaptation, evidence graphs, deterministic services, the Iron Boundary, multimodal intake, policy, action preparation, memory, learning, interface behaviour, platform integration, evaluation, privacy, and release governance.

WENI is documented as a compound system rather than a single model call. Each layer has a narrow authority and an observable failure state.
