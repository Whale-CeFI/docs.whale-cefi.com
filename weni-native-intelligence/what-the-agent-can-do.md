# What the Agent Can Do

## Explain

* translate a technical concept into an appropriate level of detail;
* explain current product or protocol state using attributed evidence;
* separate a fact, calculation, assumption, projection, and opinion;
* identify which information is missing or stale.

## Research and compare

* collect information from approved and licensed sources;
* organise chain, contract, market, protocol, document, and social context;
* compare supported paths using declared criteria;
* identify source disagreement and material changes.

## Calculate and simulate

* call approved deterministic calculation services;
* model bounded scenarios using pinned inputs and visible assumptions;
* estimate fees, timing, or outcomes within supported scope;
* invalidate a result when the underlying state expires.

## Analyse supported contracts and workflows

* resolve approved contract identity and proxy relationships;
* present known roles, permissions, dependencies, and material warnings;
* use reviewed analysis services to supplement, not replace, audit evidence.

## Prepare

* construct an inspectable possible route;
* apply hard policy and eligibility checks;
* generate an unsigned, expiring request for review where supported;
* preserve a decision record without exposing private internal chain-of-thought.

Every capability exposes its release, region, product, asset, protocol, interface, user-tier and reliability coverage as a versioned record.
