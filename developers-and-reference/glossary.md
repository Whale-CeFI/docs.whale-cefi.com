# Glossary

Plain definitions for the words used across Whale CeFi product, finance, infrastructure and AI documentation.

| Term                | Meaning                                                                                                                 |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| Asset               | A digital token such as ETH, USDT or SOL.                                                                               |
| Network             | The blockchain route used to move an asset. The same symbol may exist on several networks.                              |
| Deposit             | An external transfer that becomes an available internal balance after validation and credit.                            |
| Flexible plan       | A plan without a fixed maturity date, governed by its closure and rate-change rules.                                    |
| Fixed-term plan     | A plan that remains committed until a named maturity date.                                                              |
| Monthly reward rate | A percentage defined for one month under the published day-count and accrual rules. It is not automatically APR or APY. |
| Accrual             | Reward earned over time before or while it is posted.                                                                   |
| Ledger              | The double-entry financial record of balances, obligations and movements.                                               |
| Reconciliation      | Comparing the internal ledger with custody, provider and blockchain evidence.                                           |
| Custody             | The system and policies that control cryptographic keys and asset movement.                                             |
| Smart contract      | Code deployed on a blockchain that executes defined rules.                                                              |
| Finality            | The point at which a network transaction is accepted as sufficiently irreversible under policy.                         |
| RPC                 | A service used to read blockchain state and send transactions.                                                          |
| Audit scope         | The exact code, commit, contract, network and date examined by an auditor.                                              |
| WENI                | the native intelligence system for Whale CeFi, the crypto-native intelligence and decision-support system.                             |
| Iron Boundary       | The separation that prevents probabilistic AI output from becoming final asset authority.                               |
| Provenance          | Where a fact came from, when it was observed and how it was validated.                                                  |

The machine-readable glossary is published as a stable JSON collection with unique identifiers and aliases. Definitions used in product terms take precedence over informal explanations when a legal or financial meaning differs.
