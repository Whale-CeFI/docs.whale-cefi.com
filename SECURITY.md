# Security Policy

Do not report security vulnerabilities in a public GitHub issue or discussion.

Use only the verified security or authenticated support route published on
`https://whale-cefi.com`. If no verified security route is visible there, do not
send sensitive technical details and do not rely on an address supplied through
social media or direct messages.

The public vulnerability-disclosure route, response targets, safe-harbour terms,
PGP key, and acknowledgement policy are governed by the approved security
record in the Evidence Center.
