# Plan Catalogue

|                 | Flexible plan                                                 | Fixed-term plan                                                                                 |
| --------------- | ------------------------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| Term            | No fixed maturity date                                        | 30, 90, 180 or 365 days                                                                         |
| Rate            | May change under the notice rule                              | Fixed for the opened plan term                                                                  |
| Accrual         | Daily                                                         | Daily                                                                                           |
| Closure         | Available under the flexible-plan rules                       | Principal remains committed until maturity                                                      |
| Early condition | A closure before day 14 carries the disclosed 2.5% adjustment | Unavailable; positions redeem at maturity unless a contractually defined emergency exit applies |
| End state       | Principal and posted rewards return to the available balance  | Principal and posted rewards return at maturity                                                 |

The rate label states exactly what the percentage measures. A **monthly reward rate** is not automatically APR or APY.

### A safer way to choose

1. Decide the earliest date you may need the asset.
2. Read the exact closure rule.
3. Check the reward source and funding mix.
4. Review the calculation example.
5. Confirm only the product version shown on the final screen.

## Product-version binding

Opening a plan creates an immutable commercial snapshot containing the plan identifier, asset, term, rate numerator and denominator, day-count convention, accrual precision, rounding rule, funding schedule, fee schedule, maturity rule and disclosure version.

Flexible-rate changes create a new effective-dated schedule and a notice event. Fixed-term positions retain the schedule bound at opening unless the governing terms explicitly define another event.
