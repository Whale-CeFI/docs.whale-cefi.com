# Progression Principles

Whale CeFi’s progression system is designed around seven principles.

## 1. Valid activity

Progress must be connected to an eligible action, verified account state, approved learning result, or published reward event. Creating noise, repeating an ineligible action, or simulating activity does not create a right to XP or rewards.

## 2. Long-term progression

Levels are designed to represent cumulative participation. The system should not be configured so that a short burst of spending, account farming, or one promotional event makes long-term progression meaningless.

## 3. Clear rules

Before a user participates, the interface should show the objective, eligibility, reward, start and end time, progress measure, important exclusions, and whether review can delay final credit.

## 4. Disclosed probability

If a result is random, the relevant reward pool, odds, limits, and finality rule must be displayed before the user opens or purchases the item.

## 5. Controlled economy

XP, boosts, chests, rare achievements, and access benefits require caps, issuance rules, monitoring, and change control so that early progress remains meaningful as the platform grows.

## 6. One truth across tiers

A beginner and an advanced user may see different levels of explanation. They must not receive different progression facts. Higher access cannot remove a mandatory safety or anti-abuse control.

## 7. Reviewable decisions

Where practical, users should be able to see whether progress is pending, confirmed, expired, reversed, or under review, and how to request help if they believe the outcome is wrong.
