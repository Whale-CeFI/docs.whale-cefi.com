# Evidence Center

![The open ledger](../.gitbook/assets/06-open-ledger.png)

A diagram explains how a control is designed. Evidence shows what release, balance, deployment, audit, proof epoch, incident, or decision actually exists.

## Evidence routes

| Question                                    | Record                                                                             |
| ------------------------------------------- | ---------------------------------------------------------------------------------- |
| What company and service am I dealing with? | [Entity and Service Register](../legal-and-support/entity-and-service-register.md) |
| What rates and terms apply?                 | [Product Version Register](product-version-register.md)                            |
| What backs principal and accrued rewards?   | [Reserves and Liabilities](reserves-and-liabilities.md)                            |
| Where does reward funding come from?        | [Funding and Capacity](funding-and-capacity.md)                                    |
| What code was audited and remediated?       | [Audit Center](audit-center.md)                                                    |
| What contracts are deployed?                | [Deployment Registry](deployment-registry.md)                                      |
| What assets and networks are supported?     | [Asset Registry](asset-registry.md)                                                |
| Is a service operational?                   | [Service Status and Incidents](service-status-and-incidents.md)                    |
| What WENI release and evaluations apply?    | [WENI System Card](weni-system-card.md)                                            |
| What exact package passed release review?   | [Release Manifest](release-manifest.md)                                            |

## Evidence rule

Every record identifies scope, observation time, source, owner, status, freshness rule, limitations, and previous version. A screenshot, logo, marketing statement, wallet list, audit brand, or diagram is not sufficient evidence by itself.
